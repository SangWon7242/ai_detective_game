# AI 탐정단: 우리 주변에 숨어 있는 AI를 찾아라!

초등학교 4~5학년 AI 엔트리 수업 도입부에서 사용할 수 있는 정적 웹 게임입니다.

## 실행 방법

브라우저에서 `index.html`을 열면 바로 실행됩니다.

## 구성

- `index.html`: 화면 구조
- `style.css`: 디자인과 반응형 스타일
- `script.js`: 문제 데이터와 게임 로직
- `DESIGN.md`: 설계 문서

## GitHub Pages

GitHub Pages는 `main` 브랜치의 루트 폴더를 배포 대상으로 사용하면 됩니다.
